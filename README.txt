LAURA'S PORTUGUESE - INSTALLABLE PWA

Files: index.html, manifest.json, sw.js

FREE PUBLISHING WITH GITHUB PAGES
1. Create a free GitHub account if required.
2. Create a new PUBLIC repository named lauras-portuguese.
3. Extract this ZIP and upload index.html, manifest.json, and sw.js to the repository root.
4. In GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. After deployment, GitHub shows the HTTPS site address. Open that URL on your phone.

iPhone: Safari > Share > Add to Home Screen > Open as Web App > Add.
Android: Chrome > menu > Install app / Add to Home screen.

Progress uses browser localStorage and therefore stays on that browser/device.
Pronunciation uses the device/browser speech-synthesis voice with pt-PT requested.

NOTE: This first deployable package contains a curated starter subset sourced from the supplied guide, not the entire 1,000-item list yet. The UI and storage model are ready for the complete dataset.
